# ATM Interface - Java

## Description
This project is a Java-based ATM Interface developed as part of the CodSoft Java Development Internship. It allows users to perform basic ATM operations through a console-based application.

## Features
- Check Balance
- Deposit Money
- Withdraw Money
- Input Validation
- Menu-Driven Interface

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Visual Studio Code (VS Code)

## Project Files
- ATM.java
- BankAccount.java
