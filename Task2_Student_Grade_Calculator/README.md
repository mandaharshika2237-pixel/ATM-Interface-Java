# Student Grade Calculator

## Description
A Java application that calculates the total marks, average percentage, and grade based on marks entered for multiple subjects.

## Features
- Accepts marks for multiple subjects
- Calculates total marks
- Calculates average percentage
- Assigns grades
- Displays the final result

## Technologies Used
- Java
- Scanner Class
- Loops
- Conditional Statements
