# Quiz Application With Timer

## Description

A console-based Quiz Application developed using Java. The application presents multiple-choice questions with a time limit for each question and calculates the final score based on the user's answers.

## Features

* Multiple-choice questions with options
* Timer for each question
* Answer submission within the given time
* Automatic answer checking
* Score calculation
* Final result with correct and incorrect answers summary

## Technologies Used

* Java
* Object-Oriented Programming

## How to Run

1. Compile the program:

```
javac QuizApplication.java
```

2. Run the program:

```
java QuizApplication
```
