# Student Course Registration System

## Description
A Java console application that allows students to view available courses, register for courses, drop registered courses, and view their registered courses.

## Features
- View available courses
- Register for a course
- Prevent duplicate registrations
- Drop a registered course
- View registered courses
- Menu-driven interface

## Technologies Used
- Java
- ArrayList
- Scanner
- Loops
- Conditional Statements
